# My Portfolio

First version of my personal portfolio website built with Next.js and TypeScript.

## Overview

An earlier iteration of my portfolio site, demonstrating my journey in web development with modern frontend technologies.

## Features

- Responsive layout
- Project showcase
- About me section
- Contact information

## Tech Stack

- **Next.js** — React framework
- **TypeScript** — Type safety
- **CSS** — Styling
- **JavaScript** — Interactivity

## Getting Started

```bash
git clone https://github.com/skyson-ai/My_portfolio.git
cd My_portfolio
npm install
npm run dev
```
